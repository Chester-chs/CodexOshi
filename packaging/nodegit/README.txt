Codi for Windows x64 - Node.js 24 + Git edition

Requirements: Codex desktop (installed and signed in), Node.js 24 or newer
with npm, Git, and an internet connection. This small package does not bundle
Node.js. It downloads the pinned Codi release and Electron during installation.

1. Extract this ZIP to a folder.
2. Double-click Install-Codi.cmd and wait for it to finish.
3. Fully quit and reopen Codex. Open a new chat; Codi appears near the bottom-right.

If Codi is already installed, use Codi Settings > Quota > Check for updates >
Update now. This installer will not overwrite an existing source folder.
For a standalone installer that includes Node.js, use Codi-Setup-*-win-x64.exe.

--- 中文 ---

适用：Windows x64；已安装并登录 Codex 桌面版；已安装带 npm 的 Node.js 24
或更新版本、Git，且安装时可以联网。此小安装包不自带 Node.js，安装过程中
会下载固定版本的 Codi 和 Electron。

1. 先解压 ZIP。
2. 双击 Install-Codi.cmd，等待安装结束。
3. 完全退出并重新打开 Codex，新建聊天，Codi 会出现在右下方。

如果已经安装过 Codi，请在「Codi 设置 → 额度管理 → 检查更新 → 一键更新」
中更新。这个安装包不会覆盖已有源码目录。需要自带 Node.js 的完整安装包，
请下载 Codi-Setup-*-win-x64.exe。
