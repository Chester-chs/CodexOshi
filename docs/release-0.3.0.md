## Codi 0.3.0

**Windows x64 installer:** download `Codi-Setup-0.3.0-win-x64.exe` below, run it, then fully restart Codex and open a new chat. The installer includes an official Node.js 24 runtime and downloads Electron during setup; you do not need to install Git or Node.js yourself. Verify the download against `SHA256SUMS.txt` if you wish. The installer is unsigned, so Windows may show a trust prompt.

**Updates:** existing Codi users should open **Codi Settings → Quota → Check for updates → Update now**. The installer intentionally does not overwrite an existing source checkout or user settings.

**What's included:** quota and reset countdown, 24-hour / 7-day / 30-day local token charts, transparent character portraits with height and width controls, editable two-line dialogue, click sound with custom audio and volume, seven themes plus custom colors, a visible on/off switch, Tibo announcement checks, and one-click updates. The English and Chinese READMEs now include current screenshots, simple installation steps, and a transparent chibi example.

**Windows x64 安装包：**下载下方的 `Codi-Setup-0.3.0-win-x64.exe`，运行后完全退出并重开 Codex，再新建聊天。安装包自带官方 Node.js 24，安装时联网下载 Electron；无需自己安装 Git 或 Node.js。可用 `SHA256SUMS.txt` 校验文件。安装包尚未签名，Windows 可能显示信任确认。

**主要功能：**额度与重置倒计时、24 小时／7 天／30 天本机 token 柱状图、透明立绘和高度宽度调节、两段可编辑对话、可上传自定义音效及调节音量、七套主题和自定义配色、可见开关、Tibo 公告检查与一键更新。中英文 README 已更新为当前界面截图、简明安装步骤和透明 Q 版形象示例。
