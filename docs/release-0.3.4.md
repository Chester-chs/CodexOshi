## CodexOshi 0.3.4

Codi is now **CodexOshi**: your favorite anime or game character alongside Codex. The visible controls, update source, installer filenames, and documentation use the new name. Existing characters, colors, dialogue, sounds, and positions remain in the same local data folder.

New Windows users can download the full `CodexOshi-Setup-0.3.4-win-x64.exe` installer. If Node.js 24 (with npm) and Git are already installed, extract `CodexOshi-Node24-Git-0.3.4.zip` and double-click `Install-CodexOshi.cmd`. Check both downloads against `SHA256SUMS.txt`.

## 中文

Codi 已更名为 **CodexOshi**：让喜欢的动漫或游戏角色陪你使用 Codex。可见开关、设置页、更新来源、安装包名称和说明文档均已更新。已有立绘、配色、对话、音效和位置继续保存在原本机数据目录。

Windows 新用户可下载完整安装包 `CodexOshi-Setup-0.3.4-win-x64.exe`。如果已经安装带 npm 的 Node.js 24 和 Git，也可下载并解压 `CodexOshi-Node24-Git-0.3.4.zip`，双击 `Install-CodexOshi.cmd`。两个文件均可用 `SHA256SUMS.txt` 校验。
