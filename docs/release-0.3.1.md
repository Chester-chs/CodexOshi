## Codi 0.3.1

The compact quota bar has a lighter rounded shape, spacing guided by the golden ratio, and a crisp vector settings icon. The settings button remains clickable when Codi scales with a smaller Codex window. Documentation screenshots have been refreshed, and both READMEs now state that the transparent demo chibi was generated by GPT.

Existing users can update in **Codi Settings → Quota → Check for updates → Update now**. New Windows x64 users can download the installer below; it includes a private Node.js runtime and downloads Electron during setup. Git and a separate Node.js installation are not required.

---

额度进度条改为更轻巧的圆角形状，间距参考黄金比例；设置按钮换成清晰的矢量图标。Codex 窗口缩小时，设置按钮仍可点击。README 截图已更新，中英文说明均明确标注透明 Q 版示例图由 GPT 生成。

已有用户可在 **Codi 设置 → 额度管理 → 检查更新 → 一键更新**。Windows x64 新用户可下载下方安装包；安装包自带独立 Node.js，安装时下载 Electron，无需另装 Git 或 Node.js。
